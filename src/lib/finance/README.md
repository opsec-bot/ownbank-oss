# finance

Pure functions where possible, DB loaders take a `db` argument so tests use in-memory SQLite.

- `categorize.ts`: manual > rules (priority, then oldest) > MCC map > Income (positive) > Other. Rule field `any` matches description or payee. Amount bounds compare the absolute amount.
- `default-rules.ts`: 71 built-in payee rules (priority -100, `is_default = 1`), seeded by migration 0004 (generated by `scripts/gen-default-rules-sql.ts`). A test keeps the list and the migration in sync.
- `recategorize.ts`: re-run categorization after any rule change, live match preview, one-time pending tasks queued in `app_state`.
- `recurring.ts`: same merchant key at least 3 times, cadence weekly/biweekly/monthly/yearly (+-20%), amounts within +-15%. Manual and ignored rows survive rebuilds.
- `bills.ts`: monthly equivalents, price-up (>5% vs earlier median) and new (first seen in 30 days) flags, upcoming occurrences.
- `forecast.ts`: day-by-day projection to month end (checking available + recurring due - 60 day average discretionary spend). Warns when it dips under the buffer before the next income.
- `stats.ts`: month-to-date spend (transfer kinds excluded, trading wallet funding included), cash flow, category totals.
- `networth.ts`, `snapshots.ts`: net worth counts savings wallets only (trading wallets are shown separately), daily snapshot after sync.
- `save-plan.ts`, `afford.ts`: save suggestion per new paycheck, safe-to-spend and can-afford.
- `digest.ts`: `buildDigestData` (deterministic data for the later MCP/push step) and `renderAutoDigest` (numbers-only fallback text).
- `markdown.ts`: tiny safe markdown parser (no HTML ever produced).
- `tx-query.ts`: FTS5 search and filters for the transactions page.
- `budgets.ts`: per-category monthly limits, pace = spent / (limit x fraction of month elapsed), amber above 1.15, red at the limit, 3 month average limit suggestions, alert rules (80%, 100%, mid-month pace above 1.25 from day 10).
- `goal.ts`: one savings goal. Progress counts savings wallets only (stable, or stable + volatile). With a target date: required per week vs trailing 4 week savings transfers; also feeds the save plan (larger of the percent rule and the goal pace, still capped by bills + buffer).
- `digest.ts` also holds `publishDigest(day, markdown, source)`: stores the digest and pushes it (the step 6 MCP tool calls this).
